Diagrams live in [diagrams/](diagrams/) as `.drawio.svg` (open them in draw.io to edit). Every AWS icon is a **native shape from draw.io's own AWS library** (`mxgraph.aws4`), so in draw.io you can recolour, resize or swap it from the AWS panel. No icon files are stored in this repo: the SVG preview that GitHub shows draws the same draw.io stencil as vector paths (see [tools/drawio_aws4.py](../../tools/drawio_aws4.py)). Diagrams are generated once by `python3 tools/diagrams_aws.py`; existing files are skipped unless you pass `--force`. The first run downloads draw.io's aws4 stencil set into `~/.cache/drawio-aws4/` (not committed).
