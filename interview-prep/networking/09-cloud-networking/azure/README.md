# Level 9 · Azure Networking

> 📝 **Status: planned.** A shorter companion to the [AWS folder](../aws/README.md): the same ideas mapped to Azure names. Everything in this folder is **vendor-specific**.

| General idea | AWS | Azure |
|---|---|---|
| Private virtual network | VPC | Virtual network (VNet) |
| Stateful filtering | Security group | Network security group (NSG) |
| Custom routes | Route table | Route table (user-defined routes) |
| Managed outbound NAT | NAT gateway | NAT gateway |
| Private access to platform services | VPC endpoints / PrivateLink | Private endpoints / Private Link |
| Connecting networks | Peering, Transit Gateway | VNet peering, Virtual WAN |
| Layer 7 load balancer | Application Load Balancer | Application Gateway |
